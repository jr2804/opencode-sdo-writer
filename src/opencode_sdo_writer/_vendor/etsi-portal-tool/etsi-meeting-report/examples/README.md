# examples/

Worked examples from one past meeting of one committee. They are reference material only.

- `stq82/example-report.docx` — a prior report, anonymised (names, organisations and document
  metadata are synthetic). Use it to see the structure: section order, schedule grid, table
  styles and wording.
- `stq83/schedule-config.ps1` — a complete filled-in schedule config (topics, slot rows, document
  cells, merges). Use it as a worked example of the fields in `assets/schedule-config.example.ps1`.
- `stq83/agenda-body-template.docx` — the body template built from that meeting's agenda. For
  reference only; regenerate a template for your committee with `tools/build_template.py`.

Never copy the content of an example into a new meeting. A new meeting is designed from its own
chair's constraints and its own portal data.
